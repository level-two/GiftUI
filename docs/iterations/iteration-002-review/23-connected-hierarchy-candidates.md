was agreed, and this is a single-board fixture measurement. It does not justify
an architectural replacement or identify a remedy for the full roughly 21-second
nRF presentation gap. Counting performs incomplete semantics with different
fixtures/setup costs, so its timing is not a replacement speedup.

The counting prerequisite's 17,896-byte observed extent is useful evidence
beyond local frame sizes. It does not bound a complete replacement or simultaneous
render/state/publication work. Do not add independent maxima or reduce the
27,648-byte production reservation from these observations.
