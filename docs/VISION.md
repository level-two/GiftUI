# GiftUI Vision

GiftUI brings a SwiftUI-inspired declarative UI model to Swift platforms outside Apple's UI ecosystem, with primary emphasis on Linux and embedded systems.

Its goal is to make building interactive user interfaces on these platforms feel natural to Swift developers, while remaining flexible enough to support very different operating environments, rendering technologies, and hardware capabilities.

GiftUI should allow application code to focus on UI structure, state, and interaction rather than on the details of the underlying platform or display system.

GiftUI aims to play for Linux and embedded Swift a role similar to the role SwiftUI plays in Apple's ecosystem — while adapting that model to a much broader range of constraints and environments.
