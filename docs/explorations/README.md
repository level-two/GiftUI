# Explorations

Explorations investigate uncertain directions without requiring GiftUI to
choose or implement one. They may compare hypotheses, gather evidence, launch
Spikes, conclude inconclusively, or recommend promotion through normal gates.

- Semantics and statuses: [Documentation Rules](../engineering/DOCUMENTATION_RULES.md)
- Capture and promotion flow: [Feature Lifecycle](../engineering/FEATURE_LIFECYCLE.md)
- Starting point: [Exploration template](../templates/exploration.md)

Use `exp-NNN-short-slug.md` and the next unused `EXP-NNN` ID. Link sources and
Spikes bidirectionally. Findings are evidence, not accepted decisions.
