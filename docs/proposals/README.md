# Proposals

Proposals explain why a problem or opportunity deserves engineering attention.
They do not authorize implementation or prescribe detailed architecture.

- Canonical semantics and statuses: [Documentation Rules](../engineering/DOCUMENTATION_RULES.md)
- Lifecycle gates: [Feature Lifecycle](../engineering/FEATURE_LIFECYCLE.md)
- Starting point: [Proposal template](../templates/proposal.md)

Use filenames of the form `proposal-NNN-short-slug.md`. Allocate the next
unused `PROPOSAL-NNN` ID and add the artifact to `docs/features.yaml` in the
same change.
