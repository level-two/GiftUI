# T2.1 Nine-Class Complete Validator Evidence

Task `T2.1` replaces the declaration-stage fail-closed stub with an explicit
nine-flag predicate pass. The flags map one-to-one to
`TextResourceValidationError` raw values and are selected only after bounded
enumeration of instances, mappings, metrics, realizations, records, available
payload bytes, and the reconstructed canonical manifest.

Traversal caps protect total behavior for already-over-capacity declarations
without changing the earlier `.capacityExceeded` result. Missing or extra
accessor entries set `.invalidCount`; identities, view compatibility, metric
sign/overflow, mapping order/scalars, static and borrowed raster structure,
whole-payload SHA-256, manifest byte count, and resource identity each set
their own class independently. Available record payloads are borrowed with a
nonthrowing body, invocation-counted, structurally checked, and streamed into
one realization digest.

A complete one-instance/one-glyph/one-mapping/one-bitmap synthetic package is
valid. A simultaneous unsupported-schema, zero-count, unavailable-required,
and integrity-conflict fixture returns `.unsupportedSchema`. A separate
counter-wrapped unsupported-schema package proves that the earlier predicate
does not prevent every table, available payload byte, and canonical field from
being traversed. `check-spec-005-validator.rb` independently requires all nine
flags in exact raw order and every bounded traversal seam.
