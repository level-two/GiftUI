# SPEC-001 Integrated Cycle Evidence

The normalized Dynamic and Static fixtures execute the same complete
application/runtime opportunity. Twenty synchronous callback facts receive
sequences 1 through 20, the first fact requests one wake, and the remaining
19 coalesce. At the 250,000-microsecond boundary both profiles seal and apply
all 20 facts exactly once, dispatch one qualified semantic action against
target generation zero, produce one clean-to-dirty transition, freeze before
derivation, preserve the root model, traverse the layout/Drawing/render/
interaction stages, publish semantic revision one, and offer the frame.

The accepted case commits presentation revision one and leaves no pending
wake. The retryable-refusal case preserves the published semantic revision,
aborts the frame candidate, records `presentationPending`, and leaves exactly
one paced wake without replaying any fact or action. The Static model's direct
change route calls its caller-owned registration record while the typed root
remains address-stable for the complete opportunity. Every profile-independent
field is equal.

The checked-in normalized rows are in `integrated-cycle-cases.tsv`. Reproduce
the executable comparison with:

```sh
swift test --filter integratedAnalyzerCycleIsProfileEquivalent
```

This supplies the integrated T5.1-T5.3 and T5.5 cycle evidence. The remaining
T5.4 interaction capture/replacement boundaries are completed separately.
