# SPEC-009 T7.2 Cycle and Input Corpus Evidence

Five cycle cases cover the complete phase order, before/after-seal membership,
deferral from every active phase, ordered capacity prefixes, atomic publication,
dirty rederivation without replay, and at-most-once semantic actions. Five input
cases cover independent source sequencing and ordinals, gaps and resynchronizing
new sequences, provenance/capacity races, both exhaustion boundaries, capture
and generation-checked release, replacement, movement, disabled targets,
cancellation, and input quiescence. Acceptance rows are reciprocal.
